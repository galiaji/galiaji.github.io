# Publish on GitHub Pages

This portfolio uses `README.md` as the GitHub Pages entry page. The previous HTML preview is retained as `portfolio-preview.html`.

1. Create a public repository named `galiaji.github.io`.
2. Upload the contents of this folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, branch `main`, folder `/(root)`, then save.
5. GitHub Pages should publish the root `README.md` at `https://galiaji.github.io`.

Keep `README.md`, `style.css`, `script.js`, and the `assets/` folder at the repository root. Add your portrait as `assets/profile.jpg` if you want to replace the initials fallback.
